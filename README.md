# RIMPANGAI

## Pengenalan Tanaman Tata Boga Berkhasiat Obat Menggunakan Citra Digital dengan Metode Hybrid ResNet-50 dan Vision Transformer (ViT-B/16)

### Deskripsi
RIMPANGAI merupakan aplikasi berbasis web yang digunakan untuk 
mengidentifikasi 10 jenis tanaman rimpang berkhasiat obat menggunakan 
metode **Hybrid ResNet-50 dan Vision Transformer (ViT-B/16)**.

### Teknologi
* Python
* PyTorch
* Flask
* HTML, CSS, JavaScript

### Dataset
Dataset penelitian terdiri dari **5.509 citra tanaman rimpang**.

Link dataset Google Drive:
*https://drive.google.com/drive/folders/1VEkTUavfY_q47g3jy7hSXwbmTG69_TeX?usp=sharing*

### Cara Menjalankan

1. Install library dari `requirements.txt`.
2. Jalankan `run_server.py`.
3. Buka aplikasi melalui browser.
4. Upload gambar tanaman rimpang untuk mendapatkan hasil identifikasi.
